# 泛音复核（2026-09-28）

后续用户试听反馈与最新 P.M. / 空间效果修改见[再次复核](palm-mute-and-space.md)。下文保留当时的干声模型记录，当前试听页已更新。

## 结论与证据边界

旧版本 `7b234bf` 将所有 `◇12` 都作为同一种拨弦泛音播放，只合成四个分音，振幅为 0.82 / 0.13 / 0.04 / 0.01，高次分音的衰减时间常数只有 0.19 / 0.10 / 0.06 秒。原来的测试只证明“频率正确且有延音”，**不能证明音色像实琴，更不能证明拍泛音演奏正确**。

用户 PDF 的第 29–36 小节及重复段，在 1–3 弦上标 `Harm.`、菱形和 `12`，没有明确写 T.H.。[另一位制谱师对同一 Youngso Kim 编配的说明](https://www.guitarworld.com.cn/pu/q13170)将这个三弦动作明确描述为拍泛音。[Hub Guitar 作者的演奏教学](https://hubguitar.com/technique/tap-harmonics-overview)也将多弦一起拍击节点与逐弦拨出的泛音区分开。因此这次把本曲这类事件录为 `harmonicAttack: "tap"`；这是结合编配资料的演奏法判断，不能说 PDF 本身写了 T.H.。

[演奏者本人发布的视频](https://www.youtube.com/watch?v=65HV4ywjF_w)文字说明确认 CGDGAD、Capo 5。但本次访问其影音内容被登录/机器人验证阻止，**没有获得原演奏的音频频谱或逐帧触弦位置证据**，未做“与原录音吻合”的判断。没有导入或公开任何演奏录音采样。

## 音高与触弦位置

[UNSW 的弦振动说明](https://phys.unsw.edu.au/jw/strings.html)给出节点与振动模式的关系：有效弦长中点的泛音保留第二模态，频率为基频的两倍。[Fender 对变调夹的说明](https://www.fender.com/articles/parts-and-accessories/the-capo-6-things-you-need-to-know)指出变调夹改变有效弦长，作用相当于可移动的弦枕。

本曲继续按上传谱统一的相对变调夹品位解释 `12`，不擅自把它当作琴颈的绝对第 12 品。Capo 5 时，八度泛音节点是**相对第 12 品、实际第 17 品**。

| 弦  | 未夹空弦 | Capo 5 空弦 | ◇12 发声音高 | 频率       |
| --- | -------- | ----------- | ------------ | ---------- |
| 3   | G3       | C4          | C5           | 523.251 Hz |
| 2   | A3       | D4          | D5           | 587.330 Hz |
| 1   | D4       | G4          | G5           | 783.991 Hz |

这里“品位”表示触弦节点，不是按住后发出的音程；当前格式仍只接受相对 12 品的八度泛音，不能用普通 `+fret` 的算法推导 5/7 品泛音。此表来自谱面相对品位约定与节点公式，不是对原音频的测量。若后续演奏证据显示此谱使用绝对品位，应修订节点定义和目标音高，而不是凭听感直接升降八度。

## 本次实现

- 保留 `technique: "harmonic"`，增加可选 `harmonicAttack: "pluck" | "tap"`。旧导入谱缺省为拨弦；本曲的三弦泛音单独标拍泛音，谱面显示 T.H.，导入/导出保留该字段。
- 用 12 个受奈奎斯特频率限制的模态近似弦音，分音具有独立衰减、微小非谐性和弦间差别；目标基频保持不变。
- 拍泛音有快速起音、短促触弦噪声和低频瞬态，随后进入有音高的弦共鸣。不会额外叠加一次完整的琴身打板。
- 快速和慢速两部分衰减让起音与余音分开；延音不因八分音符时值到期直接截断。其他弦的动作不截断本弦，同弦新动作、闷音和休止仍制音。
- 缓存区分音高、弦、触弦方式与采样率。播放前准备音色，避免第一次出现的三弦泛音因现场生成样本而错开起音。

声学依据支持“触弦方式、分音及各部分衰减会改变音色”，参见 [ASA 的吉他激励综述](https://acoustics.org/pressroom/httpdocs/160th/carral.html)。**本实现的分音权重、噪声比例和衰减常数是合成参数，不是从 Youngso Kim 的吉他测量或拟合而来。** 本次没有声称改成真实吉他采样或已完成听感验收。

## 可复核的验证

- 单音：44.1 / 48 kHz 下，对 C5、D5、G5 的 120 ms 和 650 ms 窗口检测音高，误差小于 4 cents，检查波形有限、不削波、起止平滑。
- 瞬态：比较拍泛音与拨弦泛音的早期高频能量，并确认接触声衰减后音高主导。
- 和弦：实际合成的 C5 + D5 + G5 可被当前跟奏分析器匹配；低八度目标不能误匹配。
- Web Audio：离线渲染确认跨弦延音、同弦制音、掌根制音和不同触弦方式的缓存隔离；页面上直接点击第 29 小节泛音，确认三根弦以同一时间调度为 tap。
- [公开试听对照](https://example.invalid/stringflow/harmonic-check.html)：依次 C5、D5、G5、三音和弦。两版各单音前 700 ms 的 RMS 对齐；这不是完整感知响度匹配。为方便单音比较，前三个音在 1.45 秒处淡出，最后和弦保留完整尾音。演示均由代码生成，无原 PDF 或原演奏采样。

重建试听文件：`node --experimental-strip-types scripts/render-harmonic-comparison.ts`。播放器本身沿用乐谱的音量控制；试听文件额外做了 RMS 对齐，不能用其绝对音量判断谱面混音。

尚待验证：实际吉他/扬声器上的主观听感、原演奏的触弦位置和精确频谱。自动测试验证的是可测行为，不能替代这些验证。

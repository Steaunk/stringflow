# P.M. 与泛音空间复核（2026-09-28）

用户试听上一版后反馈：P.M. 不对，泛音仍不够像、缺少空灵感。本次从声源和空间效果两部分修改，而不是把“频率测试通过”当作音色验收。

## 网上资料与实际发现

- [Applied Acoustics Systems：Strum GS-2 手册，Palm / String / Body 模块](https://www.applied-acoustics.com/strum-gs-2/manual/)将掌根制音的衰减与音色分开控制，并单独描述琴体/空气腔共鸣、不同弦振动方向和分音衰减。其说明也区分近琴桥的掌根制音与松开左手造成的无音高扫擦。本网站上一版 P.M. 主要把普通振荡器低通到 `3 × 基频`，再于 90–180 ms 内衰减到接近零，缺少独立的弦激励与琴体瞬态。
- [Julius O. Smith：Artificial Reverberation](https://www.dsprelated.com/freebooks/pasp/Artificial_Reverberation.html)区分直达声、早期反射和密集的后期混响，并讨论左右声道相关性与衰减时间。上一版泛音直接送到输出，**完全没有混响**；把干弦尾音拉长不能等价地产生空间感。
- 原演奏的 YouTube 音频仍无法直接访问，未获得可分析的实录。没有依据声称这些参数来自原音频、复刻了某个混响踏板，或使用了真实吉他采样。下述系数是基于上述原理的合成设计，最终音色仍以试听反馈为准。

## 修改

### 掌根制音

普通 P.M. 起音使用单独的受阻尼弦模型：保留基频及低次分音，较高分音更快消失；叠加很短的触弦声和低振幅琴体瞬态。响度不再只是把普通音乘小系数，衰减也不随谱面音符时值机械改变。它与 `×` 死音、拍弦和打板仍是不同事件。

带连奏关系的 P.M. 保留原有可连续改变频率的弦声部，避免采样式短音切断击勾弦或滑音。也就是说，该特殊组合并未改成与普通 P.M. 完全相同的模型；普通 P.M. 的改进不能被当作所有混合技法已准确还原的证据。

### 泛音

减轻上一版拍击噪声和低频瞬态，增加慢衰减部分的比例并延长余音。实际音高沿用[上次的谱面复核](harmonics.md)，不通过升八度改变“亮度”。

泛音有独立的立体声卷积混响：约 22 ms 的预延迟、稀疏早期反射、左右不同的密集尾音；尾音做高低频限制，避免增加低频浑浊或持续嘶声。没有加入八度移调或 shimmer。P.M.、节拍器、调音参考音和麦克风不送入这个混响。

谱面底部「记号 / 音色」提供干声、自然、空灵三档，默认空灵。暂停、跳转及进入麦克风模式时清空混响处理链；同弦制音停止声源，但已经进入空间的反射自然衰减，二者单独验证。

## 验证与试听

- 44.1 / 48 kHz 下验证源曲 P.M. 低音和和弦组成音的音高、自然衰减、不削波与平滑起止。
- 验证混响预延迟、左右尾音差异、受控能量和衰减。
- Web Audio 离线渲染：干湿版本最初直达声相同；制音后只有湿声保留空间余音；停止时混响清空。
- 沿用泛音音高、同弦制音、跨弦延音、缓存、点击调度和跟奏识别测试。
- [试听页](https://example.invalid/stringflow/harmonic-check.html)比较 `9677e63`（用户刚试听的上一版）与本次版本：P.M. 前后对照，以及泛音上一版／新版干声／新版空灵。每段首个单音前 700 ms 的左声道 RMS 对齐后，用同一个增益处理整段；这不是完整的感知响度匹配。

所有试听通过真实 AudioEngine 的 OfflineAudioContext 渲染，音高和时序一致，再编码为 128 kbps MP3，避免较大的 WAV 拖慢网页加载。它们均为自有合成，不包含原 PDF 或第三方录音。

重建：先 `npm run dev -- --port 5174`，再 `node scripts/render-tone-comparison.mjs`。需要包含 `9677e63` 的 Git 历史、Chromium 和 ffmpeg。历史的 `render-harmonic-comparison.ts` / WAV 是更早的对照，不再作为当前页面试听。
